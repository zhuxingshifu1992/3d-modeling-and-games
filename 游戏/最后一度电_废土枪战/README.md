# 最后一度电 · 断电区

废土充电场中的单人第一人称关卡，包含任务流程、敌人、枪械、设备互动和程序生成声音。

## 运行

使用 Godot 4.7.2 导入 `project.godot`，首次等待资源导入，然后按 F5。Windows 可双击 `启动游戏.cmd`；启动前需要安装 Godot 并设置 PATH 或 `GODOT_BIN`。

移动、射击、换弹与设备互动按游戏内提示操作。

## 项目文件

- `project.godot`、`main.tscn`：引擎入口。
- `scripts/`：游戏逻辑。
- `assets/`：游戏所需模型、贴图、声音与数据。
- `tests/`：现有的行为与场景检查脚本。

附带角色和枪械制作源文件、装备贴图与生成脚本。场景使用公开版废土充电场，标签与照片纹理已经处理，界面使用 Noto Sans SC。

可编辑模型：[打开源文件](source/人物与枪械_精修.blend)。
