# 素材与制作来源

- 场景：由用户提供的六张充电场照片重建的《废土充电场》模型，来源工程为 `../../建模/废土充电场`。游戏资产 `assets/models/charging_yard.glb` 是该模型的项目内副本；公开版 Blender 工程位于建模分类，原始照片及照片纹理已移除。
- 保留的视觉物件：双层集装箱办公室、外楼梯、充电棚、充电舱、充电桩、售货机、冰柜、单车、电柜、工程车、道闸和工业院落。
- 游戏新增：低矮掩体、交互设备、照明与围界由 Godot 创建。为可通行性，游戏中的外楼梯向外移动 0.85 米并增加衔接平台；未修改原建模工程。
- 枪械和人物：2026-09-15 精修版使用 `source/build_detailed_models.py` 在 Blender 中生成实体几何、倒角、衣料曲面与分指手套。可编辑文件为 `source/人物与枪械_精修.blend`，五个游戏模型在 `assets/models/detail`。角色通过分层关节和双臂求解保持持枪姿态；不是扫描人物或动作捕捉素材。
- 装备材质：`assets/textures/equipment` 内的颜色、法线、粗糙度与金属度图集均在本地生成。布料、皮革、橡胶、木质和金属使用不同表面参数，没有使用外部角色或枪械资源包。
- 声音：`tools/generate_audio.py` 本地生成，WAV 位于 `assets/audio`，包括枪声、脚步、设备反馈与风声。
- 中文字形：Noto Sans SC，随附 SIL Open Font License 1.1，见 `assets/fonts/OFL.txt`。
- 引擎：Godot 4.7.2，源码版需安装 Godot 编辑器，依赖许可见仓库根目录 THIRD_PARTY.md。

这是一款照片场景衍生的单关卡游戏原型。照片未提供精确测量，场地尺寸为建模估计；实时游戏画面采用风格化材质和程序角色，不能等同于照片级扫描复刻。
