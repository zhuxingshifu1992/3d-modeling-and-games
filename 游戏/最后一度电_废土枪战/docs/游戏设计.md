# 最后一度电：断电区

## 体验目标

Windows 离线第一人称单人战役。直接复用六张照片重建的废土充电场，制作一场约 8–15 分钟、有明确目标和结局的枪战行动。玩家为失去供电的聚落医务站带回储能电池。主题是“抢回足够撑过一夜的电”，所有主要交互围绕原场景的电箱、充电桩、办公室与道闸展开。

## 完整关卡

1. 南侧道闸进入。无线电交代目标，首批巡逻掠夺者 3 名。办公室平台的电力开关是第一目标，外楼梯提供高低变化，平台有一次弹药补给。
2. 合闸后充电棚设备发出青色灯光。玩家前往 02 号桩启动电池充能。充能需 75 秒，允许离开桩位迎敌。敌人通过厂房前沿和工程车外侧两条路线增援，最多 5 名同时战斗。
3. 充能达到 35 秒时只跳闸一次。进度保留，玩家要去售货机附近电箱复位，迫使换位。黄色预警灯、提示音和明确文字同时通知，不用靠猜测找开关。
4. 充满后取走电池，出口亮绿灯。两名追兵加入，玩家可以立即撤离，无需歼灭全场。到达道闸并完成 3 秒撤离即可胜利，展示时间、命中率、爆头与消灭数。

任务目标不可摧毁，不因敌人寻路失败而锁住流程。状态依次为 POWER、CONNECT、CHARGE、RESET（保留充能）、COLLECT、EXTRACT、VICTORY。合闸和开始撤离存检查点。死亡可重试检查点或重新开始；暂停菜单提供继续、重试和退出。

## 战斗与角色

- 玩家 100 生命、35 护甲，走路 4.5m/s、冲刺 7m/s、蹲伏 2.3m/s，跳跃可跨过小障碍；蹲伏降低视点与碰撞高度。
- R7 卡宾枪：24 发弹匣，120 发储备，自动射击，右键瞄准，射击有小幅随机散布、后坐力与弹壳。近中距离主要武器。
- 破门者霰弹枪：5 发装填，20 发储备，近距离散射，低射速、高单次伤害。数字键或滚轮切枪。
- R 换弹，Q 急救（初始 2 次、恢复 45 点生命），E 按住交互，Esc 暂停。空弹匣和不可用交互有清楚反馈。
- 射手保持中距、寻找视线；侧袭者沿两翼接近；重装守卫移动较慢但血量更高。所有射击必须通过真实遮挡射线，不穿墙；开火前有短暂停顿和可见枪口/示警。
- 人物为带面罩、护甲和背包的可辨识三维敌人，有行走摆臂、受击、死亡倒地反馈。爆头伤害更高。敌人不从玩家身边或视野正中心突然生成。

人物与枪械采用可编辑 Blender 模型。三类敌人共享约 1.77 米的人体比例，通过帽盔、衣色、面罩、护具和负重区分身份；服装使用曲面体积，手套带独立手指与关节。双臂根据枪身握持点求解姿态，抬枪、放低武器时手掌随枪移动。R7 和霰弹枪具备倒角机匣、扳机护圈、枪管、瞄具、机械附件与分层材质；第一人称显示双手，R7 换弹时弹匣独立移动。共用 PBR 图集限制材质绘制开销，近景细节服务于实时游戏表现。

## 场景与可读性

原集装箱楼、充电棚、白色充电舱、售货机、冰柜、健身单车、四辆工程车和道闸完整保留。主院落增加两组低矮货箱/路障，让开放区域有可用掩体。侧翼围界、远景残骸与低雾延伸世界观，不无限扩张地图。

车体、白舱和实体墙是可靠掩体。铁丝网、枝叶、细电缆及垃圾不产生阻塞玩家的小碰撞。外楼梯采用平滑坡道碰撞与真实平台碰撞，避免逐级绊脚。角色不能走出场地边界或钻入封闭模型。

黄昏沙尘色调，青色只用于电力、交互与任务方向；锈红用于危险和受击。HUD 使用工业电表意象：左上当前任务，底部生命/护甲与武器弹药，中心细准星与交互环，受击时显示方向。主菜单展示场景实景和操作说明，包含开始行动、难度、鼠标灵敏度和画质选项。

声音包括枪声、弹壳、击中、换弹、脚步、跳闸、接通、告警和风声。程序合成的本地 WAV 不依赖联网。枪声按距离衰减，字幕承载所有必要剧情信息。

## 平衡与验证

初始 3 敌、合闸后最多 2 增援、充电期间 3+3（含一名重装）、撤离时 2 名，总数约 13。简单/标准通过敌人精度、伤害和补给调整。资源有限但固定补给点足以通关。最佳成绩单独保存在游戏专属 user:// 目录，不修改其他游戏存档。

交付包含独立 Windows EXE+PCK、完整 Godot 工程、中文说明、截图和测试记录。采用 GL Compatibility 适配本机 Radeon 集成显卡。验证覆盖装弹/伤害/任务状态、暂停/重开/胜负闭环、资源导入与独立包运行；实际 GPU 截图用于检查可见效果。
