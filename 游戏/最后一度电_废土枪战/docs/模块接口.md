# Module contract — Godot 4.7.2

Coordinates Godot Y up, original Blender (x,y,z) -> Godot (x,z,-y). Original yard ground x[-25,25], z[-29,25]. Office centered (10,0,0), x7..13,z-2.5..2.5; terrace z2.5..4 y3.0; stairs x13.4..14.9,z-0.7..6.3. Canopy x-11.3..-2.8, z-16.4..5.4. Trucks x6,10,14,18,z-12.5. Warehouse x[-14,20],z[-29,-22]. Player start (0,0.15,21). Ground-level positions have y=0.05 before character offset.

Avoid class_name (use preload paths) to remove import ordering cycles. Avoid Variant inference warnings: use explicit types for math with untyped values. No edits outside assigned files. Root creates project.godot, main.tscn, scripts/game.gd, player.gd, weapon.gd, run_state.gd, tools and tests.

## World — scripts/world.gd extends Node3D
`build() -> void` called after add_child, instantiates res://assets/models/charging_yard.glb. Create all fixed collision with collision_layer=1/mask=0. Player layer=2 mask=1|4; enemies layer=4 mask=1|2|4. Non-solid decoration no collider.
`find_path(from: Vector3, to: Vector3) -> PackedVector3Array` ground navigation avoid real solid boxes; `is_walkable(p:Vector3)->bool`. Do not override Node.get_path.
`set_power(on:bool, alarm:bool=false)->void`; `set_quality(low:bool)->void`.
`get_cover_points()->Array[Vector3]` optional.
World does not create game objectives, enemies, pickups or player. Root does those. Power console root will place at (10.9,3.0,3.55) with activation center y+1; make walkable terrace. Charge objective (-8.3,0,-7.5), reset cabinet (-8.9,0,.55), battery same charge, extract (0,0,20). Must all reachable. Static ground nav ignores upstairs platform except root handles console using Euclidean reach.

## Enemy — scripts/enemy.gd extends CharacterBody3D
Signals `died(enemy, headshot: bool)` and `fired(origin:Vector3,target:Vector3)`.
`setup(game:Node, kind:String, start:Vector3, seed_value:int)->void` AFTER add_child. Set game ref, position. Kinds rifle/flanker/heavy. Use game.player and game.world. Player exposes `take_damage(amount:float,source:Vector3)->void`, `is_alive()->bool`; game exposes `can_fight()->bool`, `play_sound(key:String,pos:Vector3=Vector3.INF)->void`, `spawn_tracer(a:Vector3,b:Vector3,color:Color)->void`.
`take_damage(amount:float, hit_position:Vector3, headshot:bool=false)->void`; `is_alive()->bool`; `alert_to(point:Vector3)->void`.
Enemy belongs group enemies and has health/dead variables. Collision primary capsule radius .34 height1.75, center y.9; headshot evaluated by root as hitpos.y > global_position.y+1.42. Root keeps enemies array and removes after died. Corpses may persist ≤10sec then queue_free. Use actual physics ray to decide LOS; cannot shoot through static walls. AStar world path supports ground AI; all enemy starts are ground. No global class_name.

## HUD — scripts/hud.gd extends CanvasLayer
Signals `start_requested(difficulty:String)`, `resume_requested`, `retry_requested`, `restart_requested`, `quit_requested`, `settings_changed(settings:Dictionary)`.
`setup()->void` after add_child builds all UI, font res://assets/fonts/NotoSansSC.ttf.
`show_menu(best:Dictionary={})`, `show_pause()`, `hide_panels()`, `show_end(won:bool,stats:Dictionary)`.
`update_hud(data:Dictionary)->void`: data keys health,armor,ammo,reserve,weapon,medkits,objective,detail,phase,charge,stamina,spread,aiming,kills,carrying,elapsed.
`set_interaction(text:String,progress:float)->void`, `show_message(title:String,body:String,duration:float=5.0)->void`, `hit_marker(headshot:bool=false)->void`, `damage_flash(direction:float=0.0)->void`.
`set_objective_marker(screen_pos:Vector2,distance:float,visible:bool)->void` optional if root implements marker. HUD does not pause tree itself; signals root owns pause. Root will call pause and still allow HUD PROCESS_MODE_ALWAYS.
