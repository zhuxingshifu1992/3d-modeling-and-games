# 写实建模升级

用户反馈：建模必须逼真。上一版的胶囊式肢体、简化衣物、团块树叶、平面云和均匀岩坡不满足要求。

本次按写实实时游戏标准改造已授权的本项目，保留同一赛道和操控接口。

## 工作内容

- 人物：以具有真实人体拓扑、完整 UV、皮肤与面部贴图的专业骨骼人物为基础，重做压弯姿态和服装配色；保留红帽、白衣、绿色短裤、红白鞋的参考识别特征。输出可编辑源文件及游戏 GLB，避免继续由分离圆柱关节拼接人体。
- 滑板：保留尺寸与四轮结构，为木层、砂纸、金属桥和鞋底完善材质与真实尺度。
- 环境：使用有明确许可证的实拍 PBR 表面，区分岩壁、泥土、柏油与植被；在近景使用树枝与叶片层次，替换几何团块。
- 光照：真实天空环境贴图与方向光匹配；降低过曝、检查肤色，增加合理接触阴影。优先验证本机能稳定运行的渲染方式。
- 验收：相同实机镜头比较改前改后；人物近景检查脸、手、关节、衣物与贴图，场景检查重复纹理、路缘穿插和叶片透明。最终重新打包、测试真实独立包。

## 文件边界

人物代理拥有 rider.gd、assets/rider_realistic、source/rider 与人物工具；环境代理拥有 world.gd、assets/environment 与环境工具。主任务处理光照、集成、打包、性能和视觉验收。原参考视频与其他工程不修改。

## 检验原则

不以提高面数代替写实，不把概念图或离线渲染图当成游戏实时画面。不在未经实机检查时宣称达到真人或照片级。第三方资源保留来源、许可和改动记录。
