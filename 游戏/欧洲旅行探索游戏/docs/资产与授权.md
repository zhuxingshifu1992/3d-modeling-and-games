# 资产与授权

本说明对应“欧洲漫游”游戏目录。第三方资产的来源清单保存在 [assets/textures/photographic/sources.json](../assets/textures/photographic/sources.json)；字体与引擎许可原文随项目一同提供。

**模型与生成内容。** 建筑、地形、道路、家具几何和游戏脚本在本项目中生成与组织。地标采用建筑特征参考和压缩尺度的艺术化重建，不是数字扫描或测绘数据。项目目前未附加统一开源许可证；本说明仅登记第三方来源，不另行为整个项目指定发行许可。旧版场景保留在原有目录，升级内容位于当前游戏项目。

**图像材质。** 当前材质库包含 32 个语义材质。10 套来自 Poly Haven 的 CC0 PBR 图像资源，每套使用基础色、粗糙度和法线贴图，共 30 张图像；其余表面使用项目生成的图像贴图与材质参数。语义材质与第三方贴图套数是不同统计口径。应用映射可在 `tools/model/materials_v2.py` 中查看。
