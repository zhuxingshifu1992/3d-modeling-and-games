# 欧洲漫游 · 旅行手记

连接法国、意大利、瑞士、德国四个艺术化景区的探索游戏，包含可进入的建筑、旅行记录和地标互动。

## 运行

使用 Godot 4.7.2 导入 `project.godot`，首次等待资源导入，然后按 F5。Windows 可双击 `启动游戏.cmd`；启动前需要安装 Godot 并设置 PATH 或 `GODOT_BIN`。

移动、交互、地图及旅行记录按游戏内提示操作。

## 项目文件

- `project.godot`、`main.tscn`：引擎入口。
- `scripts/`：游戏逻辑。
- `assets/`：游戏所需模型、贴图、声音与数据。
- `tests/`：现有的行为与场景检查脚本。

附带当前可进入建筑的 Blender 源文件和区域 FBX；独立外景模型另见建模分类。

可编辑模型：[打开源文件](source/欧洲漫游_可进入建筑.blend)。
