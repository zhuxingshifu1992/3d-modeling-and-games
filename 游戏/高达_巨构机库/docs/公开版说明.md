# 公开版处理说明

发布日期：2026-09-24。由当前制作工程建立独立发布副本；制作原件不受影响。

## 与制作版的差异

- B2 飞翼采用 `assets/models/wing.glb` 中已有的程序模型和标准驾驶舱配置，保留第六个登舱与启动记录位置。来源存疑的下载模型及其贴图、原包、派生图片均不发布；来源事实与推断见 [飞翼源模型审查](飞翼源模型审查.md)。
- 中文字体使用 Noto Sans SC / SIL OFL 1.1，替换制作机的系统字库。
- 独角兽原 GLB 超过 GitHub 的 [100 MiB 单文件限制](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)。将 80 张内嵌图像移至相邻文件，并重排二进制缓冲偏移；几何缓冲和清理后的图像字节保持一致。请保留整个 `assets/models/` 目录。
- 清理文本、本机绝对路径、个人标识、会话记录、图片元数据和 Blender 保存路径；Blender 贴图重新检查。
- Windows 启动脚本和打包脚本通过已安装的 Godot 运行，不依赖制作机路径。

## 收录内容

Godot 源码、场景、音效、运行所需模型与贴图，程序模型 Blender 工程，RX-78-2 与沙漠扎古的游戏派生 Blender 工程，建模/转换脚本、现有适用测试、署名许可与部分预览。

上游下载原包、编辑器缓存、旧可执行包、诊断日志、过程截图、个人检查点、官方参考图片/手册及下载版飞翼资产不在此次源码快照中。其他机体的派生 GLB 可在 Blender 导入编辑；从上游重新转换需要按素材来源说明取得相应原件。随附转换报告中的来源哈希和旧游戏资产哈希是制作时证据；当前发布字节以仓库根目录 `MANIFEST.sha256` 为准。

现有精细舱室测试只针对公开版仍使用精细资产的机位；飞翼由完整行走与登舱流程检查覆盖。没有把下载版飞翼测试的历史结果当作公开版结果。
