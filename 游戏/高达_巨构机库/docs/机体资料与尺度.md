## 驾驶舱位置

- 飞翼零式EW：上述官方说明书PDF第8页、印刷页14的舱门开启图显示躯干前部中央开口，支持把平台放在胸腹中央区域，不能证明精确离地高度。
- 强袭自由：[官方实物大胸像驾驶舱报道](https://www.gundam.info/special-series/weekly-gundam-news/special-series_weekly-gundam-news_20120731_812p.html)支持胸部/躯干范围，没有精确入口高度。
- 能天使：上述Bandai说明书PDF第9页、印刷页16的「コクピットハッチの開け方」明确展示胸腹正面中央舱盖开启位置。可用于匹配外观舱盖，不能从图中推出精确离地高度或足够站立的人尺度净空。游戏内舱仍按实际模型适配。
- 元祖、ν、独角兽：本资料本轮未补充可直接引用的官方驾驶舱位置图。游戏中的胸部登舱与内部布局属于体验设计，不代表已确认的官方结构。
- 实装已对六台模型分别留出胸舱空间，并以GLB三角形检查舱口净空。座椅、内舱空间、登舱桥和传感器挂点分别定位；驾驶员座位高度与头部摄像机高度不是同一个值。

## 比例示意采用的设计值

人物1.75米，站立视线1.65米，人行门2.1米，机库净高34米。人物和门均放在与机体相同的地面，使用统一线性尺。

- 元祖对人物：18 / 1.75 = 10.2857倍。
- ν高达对人物：22 / 1.75 = 12.5714倍。
- 可交互示意中的登舱平台高度取机体高度的0.6倍，只用于说明上升过程的观察高度，是体验设计值，**并非官方驾驶舱高度**。

示意使用抽象机甲轮廓，只验证比例，不代表最终外观。视觉概念图同样不能作为资产包围盒或机体尺寸的测量依据。

## 实装尺寸

六台GLB使用统一米制，脚底位于Y=0，节点缩放为1。元祖与ν以头顶高定标；独角兽毁灭模式和强袭自由按包含天线的机体本体全高定标，背包装备单列；飞翼零式EW与旧版能天使以所列数值作为原型头顶参考高度。2026-09-23确认能天使官方说明书为全高18.3米，已取得的能天使精细模型按此字段定标，完整头盔最高点18.3米，脚底为0；B3使用无手持武器的PG造型整备状态。原型清单仍保留历史，精细模型验收见[公开版验证](公开版验证.md)。详情见 [模型清单](../assets/models/model_manifest.json)（历史程序模型清单；当前公开版检查见公开版验证）。

能天使说明书：[Bandai 官方手册](https://manual.bandai-hobby.net/pdf/572.pdf)。仅用于比例与结构参考，公开仓库不附参考手册副本。


### 2026-09-23 飞翼EW实物素材定标

B2采用用户下载GLB中的EW羽翼机型。官方手册HEIGHT 16.7m未定义测量端点；游戏以脚底至作者头盔天线顶端16.7m作为约定，羽翼与身体统一缩放，当前静态停泊姿态翼顶约19.44m、翼宽约21.19m。人物1.75m、眼高1.65m。原机骨骼姿态已烘焙，胸盖和内舱为交互适配，无飞行或变形。官方依据见source/references/wing/OFFICIAL_REFERENCE_NOTES.md，实际边界以source/external/wing_sketchfab/derived/conversion_report.json为准。
