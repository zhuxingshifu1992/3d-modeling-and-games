# GUNDAM · 巨构机库

先安装 Godot 4.7.2 并将其加入 PATH，或设置 GODOT_BIN，然后双击本目录的 **启动游戏.cmd**，再选择“进入机库”。显卡较慢时使用 **流畅模式.cmd**。也可在 Godot 编辑器导入 project.godot 后按 F5。

这是一个Windows离线单人机库探索原型：第一人称行走、实体升降平台、进入驾驶舱与启动检查。元祖 RX-78-2（A1）、ν 高达（A3）、独角兽毁灭模式（A2）、强袭自由（B1）和能天使（B3）已使用外部模型；公开版飞翼零式EW（B2）使用本工程已有的风格化程序模型。机库最深处有沙漠扎古观摩展位，暂不登舱。

## 操作

| 按键 | 操作 |
| --- | --- |
| W / A / S / D | 行走 |
| 鼠标 | 自由观察，可向上看机体 |
| Shift | 快走 |
| Ctrl | 蹲下观察 |
| E | 根据屏幕提示操作升降台、舱门、驾驶舱与仪表 |
| Q | 在驾驶舱内随时关机离舱 |
| F | 开关工作灯 |
| Tab | 机体导览，选择步行导航目标 |
| Esc | 暂停/恢复，调节视场角、灵敏度、声音，返回入口或退出 |
| F2 | 隐藏/显示游戏界面，便于截图 |

## 怎么登舱

1. 依据左上角导航前往机体前方。找到黄色护栏的升降平台，走到台面中间。
2. 按E上升。升降时仍可转头观察；抵达后可恢复行走。
3. 沿检修桥走近胸部舱门，按E开门，等舱门打开后再按E落座。
4. 三次按E依次接通辅助供电、外部监视器和系统自检。完成后保存该机体的启动记录。
5. 按E或Q离舱，沿桥返回平台，按E下降。继续选择其他机体。

六台机体全部完成自检后，右上角显示6/6。自由观摩不受任务或时间限制。导航只指路，不会把人直接传送到驾驶舱。

RX-78-2 在桥上的黄色等候线外开盖；舱盖先向外移，再向上打开，踏板随之搭接。离舱时会先等舱盖完全打开，再起身返回检修桥。

ν高达也使用活动胸盖，登舱层约16米高。沿检修桥走到舱前，按E会在需要时先辅助横移对齐，再打开舱盖，无需手动找准厘米级中心。开盖后再按E落座，离舱时会等待舱盖完全打开。辅助仅在宽桥等候区启用；已经走进狭窄对接踏板后，仍需保持居中，或退回宽桥再按E。

能天使在B3，升降层约12.1米。沿桥到舱前按E，身体有偏移时先辅助对齐，原中央舱盖随后外移、向下打开；完全打开后对接踏板接通，再按E落座。离舱时同样等待舱盖和踏板就绪。此模型为PG造型、无手持武器的整备状态。

强袭自由在B1，胸部检修层13.75米。沿桥走近后按E，必要时先辅助对齐，再将中央胸甲向外移并抬起；舱盖完全打开、踏板接通后再按E落座。保留原模型金色内构、双枪和翼组。

独角兽在A2，胸部检修层15.25米。沿桥走到等候区按E，偏心时先辅助对齐；中央胸盖向外移后抬起，待踏板接通再按E落座。保留原白甲、红色框架、刻线与标识，头部翻面缺陷已局部修复。素材许可为CC BY-NC 4.0，仅用于非商业用途。

飞翼零式EW在B2，采用程序模型与标准驾驶舱，检修层约10.02米。按E乘升降台、沿检修桥开门并落座，完成三步启动后按Q离舱。

## 比例与画面

驾驶员身高1.75米，站立视线高1.65米；人物、门、工具柜、维修车与机体使用统一米制。屏幕左下角显示当前人眼离地高度。机体设定与尺寸口径见 [资料与尺度](docs/机体资料与尺度.md)，原型本体与装备包围高度见 [模型清单](assets/models/model_manifest.json)。

RX-78-2 按不含V天线的头顶18米校正，沙漠扎古按暂定展示头高17.5米校正，原作者为AnonmalyFound。ν高达按22米头顶校正，包含浮游炮的装备总高约28.55米，保留Ryanwill679/TrashCG的双侧浮游炮造型。来源和改动记录见[素材来源](assets/机体素材来源.txt)。活动胸盖和驾驶舱为游戏适配，并非完整原作内构复刻。能天使按官方全高18.3米校正，原模型署名yqms，保留原分色与顶点颜色。强袭自由原模型署名K0077，本体按18.88米定标，保留翼组后装备总高约19.45米。独角兽原模型署名kurojishi，采用原始2K贴图和红框毁灭模式，按21.7米全高定标；脚底至作者头盔天线为游戏定标约定。飞翼程序模型按16.7米机体高度制作，包含风格化羽翼。公开副本未收录下载版飞翼，原因见[来源审查](docs/飞翼源模型审查.md)。独角兽与ν高达使用分区全景监视器；其他机体使用中央实时画面和各自系统仪表。舱内视频来自机库中的机体传感器摄像机，不是背景图片。

本版提供机库探索和静态机体启动体验，尚无战斗、机体行走、飞行或变形。设计阶段的概念图是美术方向参考；精细换模前的历史实机截图未收录。`previews/refined_game`、`previews/refined_nu_game`、`previews/refined_exia_game`、`previews/refined_freedom_game`、`previews/refined_unicorn_game` 为从游戏几何导出的CPU结构预览，灯光与实时引擎画面不同。

## 保存与文件

- 启动记录、视场角、鼠标灵敏度和声音设置自动保存在 `%APPDATA%\GundamHangarPilot\pilot_profile.json`。
- 暂停菜单的“返回入口”会复位升降台和临时登舱状态，但保留完成记录。
- 此公开仓库不附 EXE/PCK；可从源码运行或自行打包。
- `source/机体模型.blend` 与 `source/build_models.py` 是可编辑模型和生成源；`project.godot` 是游戏工程入口。
- 流畅模式降低分辨率、关闭抗锯齿和实时阴影，降低驾驶舱监视器分辨率。

## 源码重建

在项目根目录用已安装Godot先执行 `--headless --editor --path . --import` 导入资源，然后用 `--headless --path . --script tools/pack_game.gd` 打包。工具可通过 `-- --engine=<Godot EXE绝对路径>` 指定运行时。也可设置 GODOT_BIN；未指定时使用当前运行打包脚本的 Godot 可执行文件。
