# 威尼斯水城

威尼斯风格的彩色街屋、桥梁、运河、教堂与贡多拉场景。

## 打开与编辑

使用 Blender 5.2.1 打开 [威尼斯水城.blend](威尼斯水城.blend)。模型贴图已打包；编辑前可另存一个工作版本。

包含全部程序建模脚本和一个附带的场景版本 `威尼斯水城1.blend`；游戏用 GLB 位于关联游戏。

## 预览

![威尼斯水城](预览_城市全景.png)

## 重新生成

在本项目目录运行：

```console
blender --background --python scripts/build_city.py -- --no-render
```

重建会更新本目录下的生成文件。
